# Web v0.9.1：原版画质触屏适配

## 本轮范围

继续原有 Web 游戏，不另做简化移动版。屏幕截图显示附件预览中的未样式化文档，包含本应隐藏的失败提示；这不足以证明 WebGL 曾执行或失败。因此修复入口说明、加载保护、多点输入与安全区布局，不能用一张截图断言手机 GPU 问题已经解决。

## 已实现

- 无脚本入口说明与隐藏的游戏容器；真正执行首脚本后才切入游戏界面。提示手机使用 Safari/Chrome 的完整 HTTPS 页面，避免把 HTML 附件预览当作游戏。
- 单一摇杆指针所有权、12% 死区、单位长度速度上限；另一指按技能立即施放。合成点击不会重复攻击，键鼠点击仍支持。
- 取消触摸、捕获丢失、失焦、切后台、页面恢复和视口变化时复位输入；旋转屏幕暂停，不强制旋转或锁屏。
- 安全区、动态可视高度、横竖屏 UI；触屏镜头面板从战斗技能区移至右上角入口，长菜单和抉择可滚动。
- 图集顺序解码，减少同时进行的临时解码工作，不改变图片、动作、纹理分辨率或场景。没有做真实设备内存基准测试。
- 启动 watchdog 改为每阶段连续 25 秒无进展，不再因为多个正常阶段累计时间过长误报；成功后不会被晚到进度重启。
- 默认保留精致画质。WebGL 创建失败明确报错，不自动替换为 2D；显式确认才可启用旧 Canvas 兼容模式，并标明不同画质。上下文丢失暂停、尝试保存，再提示原画质重载。
