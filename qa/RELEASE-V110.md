# Web v0.11.0：NPC 支线与选择结算

本版本建立在 Web v0.10.0 的抽象剧情、NPC 梗气泡和原版 HD-2D 场景之上，增加可推进、可回访、可二选一结算的 NPC 支线。没有替换 PNG、Three.js 建筑、角色动作或触屏输入层。

## 新增内容

| 项目 | 数量 | 运行时行为 |
|---|---:|---|
| NPC 支线 | 5 条 | 每个战役区域 1 条，接取后绑定当前区域目标 |
| 支线目标 | 4 类 | 吞噬、地标、连噬、Boss 击败 |
| 结算选项 | 10 个 | 每条支线 2 个方向，奖励为经验、生命或永久精华 |
| 支线记录 | 最多 5 条 | `sideQuestLog` 防止重复结算，选择结果保存到 NPC 回声 |

支线顺序与区域主题保持一致：冲水前的三口 → 对不上的账 → 英雄需求变更 → 合规连噬 → 脚注里的终点。完成目标后回到任务 NPC，使用原有探索选择面板作出二选一；取消面板不会消耗任务，确认后才写入完成记录。

## 状态与兼容

- 旧存档继续使用 schema 1；缺少 `sideQuest`、`sideQuestLog` 的存档会安全迁移。
- 0.10.0 中已经交谈过任务 NPC 的存档会迁移为进行中状态，不会卡在不可接取状态。
- 五王试炼不生成 NPC 支线，原有试炼节奏、补给和升级规则不变。
- 支线奖励使用定义侧数据结算，事件面板只展示结果；经验、生命和精华不会因重复点击重复发放。
- 支线完成提示显示在 NPC 头部梗气泡中；旅途中回到 NPC 附近后再次按 F 或触屏交互即可进入选择面板。

## 上线后验收

1. 在 GitHub Pages 或完整 HTTPS 页面确认菜单显示 v0.11.0 WEB。
2. 新手村与 NPC 交谈，确认头部气泡变为支线接取提示；吞噬 3 个单位后回到泡泡处，确认出现两个选择。
3. 在选择面板中刷新或继续旅程，确认事件状态可恢复且取消不会消耗支线。
4. 选择奖励后再次靠近 NPC，确认不重复打开同一支线；Canvas 参数路径仍能显示 NPC 与完成气泡。
5. 在 Safari / Chrome 触屏页面验证靠近、交互按钮、旋转暂停和安全区布局。
