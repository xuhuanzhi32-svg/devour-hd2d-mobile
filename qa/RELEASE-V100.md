# Web v0.10.0：世界回声与 NPC 梗气泡

本版本建立在已发布的 Web v0.9.1 之上，继续使用同一份原版 HD-2D HTML。新增内容不替换角色 PNG、建筑、Three.js 场景或手机触控输入层。

## 内容数据

| 项目 | 数量 | 运行时行为 |
|---|---:|---|
| 区域回声 | 5 段 | 进入区域时写入 storyBeat，J 旅途记录展示完整主题线 |
| 结尾主题 | 1 段 | 旅途记录显示“世界的解释”余味 |
| NPC | 10 名 | 每个战役区域 2 名，固定坐标，靠近后 F / 触屏交谈 |
| 梗气泡 | 30 条 | 每名 NPC 3 条，按游戏时间确定性轮换，靠近时显示在头部 |
| NPC 奖励 | 10 份 | 每名 NPC 每局只结算一次；奖励类型为生命、经验或永久精华 |
| NPC 记录 | 最多 10 条 | 写入 npcLog，旧存档缺字段时自动补齐 |

剧情主题顺序为：被丢弃的意识 → 无名的饥饿 → 英雄形状的空洞 → 被同意的边界 → 规则的余味。NPC 的玩笑承担“解释世界规则”的轻量入口，不改变战斗数值平衡。

## 存档与边界

- 继续兼容原有 schema 1 存档；旧存档没有 storyBeat、storySeen、npcLog、npcDialogue 时会迁移为安全默认值。
- NPC 坐标和文本来自内置常量，重新进入区域时重建，存档只保存交谈 ID 与短暂气泡状态。
- npcLog 最多 10 个有效 ID；气泡文本、结束时间和剧情 ID 均有长度/数值校验。
- 交谈奖励先记录再保存，重复按 F 不会重复发放；进入五王试炼时不生成补给 NPC 的额外奖励循环。

## 渲染路径

- Three.js：NPC 使用共享 ring/cylinder/rock/octa 几何，getMetrics() 报告 npcs 数量。
- Canvas 兼容路径：使用同一组坐标绘制二维 NPC 标记，不会丢失头部气泡 DOM 层。
- 头部气泡位于既有 #labels 层，使用 HTML 转义；隐藏菜单、观景模式和不可见区域不会显示气泡。
- 手机继续保留原版精致档默认策略，不因 coarse pointer 或用户代理切换渲染质量。
