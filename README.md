# 噬界 · HD-2D 电脑版原画质 + 触屏控制

公开试玩发行页。网页包含完整五区域战役、角色动作帧、触控摇杆、四项战斗动作及游戏 UI。

- 版本：0.6.0（出身与五王试炼更新）
- 新内容：4 种实际影响战斗的出身，战役通关解锁五王试炼，最近 8 局战绩与分模式/难度的最快通关纪录
- 试炼：Lv.8、7 次初始基因选择，强化五王连战；前四王各追加 2 次选择，入场恢复生命/能量与技能冷却；通关结算 80 精华
- 已有内容：15 处探索事件、45 个成本/奖励选项、8 件战斗遗物、8 项跨旅程成就
- 探索：靠近金色地标后按 F / 触屏调查；选择时世界暂停；图鉴和成就在菜单或旅途记录中查看
- 存档：兼容 0.4 / 0.5 旅程与永久成长；旧通关解锁试炼，但不伪造历史战绩；继续旅程不重复施加出身属性。战绩仅存于当前浏览器，不是线上排行榜
- 画面：与电脑版单文件逐字节一致；原始 PNG、Three.js 透视场景、灯光、阴影和后处理全部保留
- 战斗：Z / 触屏主动三段撕咬、三种精英词缀、五区限时狩猎、战利品与区域机关
- 触控：粗指针或混合触控设备自动显示左侧摇杆与右侧四个战斗键，并适配安全区
- 兼容：WebGL 失败时自动切换 Canvas 2D 渲染，不阻断启动
- 性能：静态角色图集由 16 个重复 GPU 纹理改为 1 个共享纹理与每角色独立 UV
- 建议：手机横屏、Safari/Chrome 最新版
- 构建：完整电脑版单文件、无外部运行依赖、不做移动端素材转码
