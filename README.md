# 噬界 · HD-2D Web

桌面浏览器为本轮开发目标。保留既有五区域、角色动作帧与 Three.js HD-2D 渲染，在同一网页内持续升级；本轮不另做手机版或移动端包。

- 版本：0.8.1 WEB（精准闪避、统治者破势与兼容画面修复）
- 精准闪避：敌方攻击实际命中的 0.3 秒内按 Q 冲刺可无伤闪避，获得 16 点终极能量并削减 1 秒脉冲冷却；每次冲刺只可触发一次
- 统治者破势：对同一 Boss 完成 3 次精准闪避，清除其尚未触发的攻击和在场弹幕，打开 2.5 秒破势窗口；窗口内承受伤害提高 35%，Boss HUD 实时显示破势进度
- 新内容：每个战役区域 6 个可破坏补给，共 30 处；补给箱、精华罐、经验罐分别掉落生命/精华/经验，需拾取，已破坏状态保存在本局；试炼不额外投放补给
- 连噬：4 秒内继续吞噬延续计数，3 连起每次额外恢复 1–5 点终极能量；受伤或超时中断。伤害数字、终结击大字与剩余连噬时间直接反馈
- Web 操作：WASD 移动，Z 或鼠标右键定向撕咬，Space 脉冲、Q 冲刺/精准闪避、E 终极、F 调查/出口；滚轮或滑条 75–135% 缩放；P 暂停观景，P/Esc/按钮退出，观景时战斗冻结
- 成长：4 种出身、通关后五王试炼、最近 8 局战绩与分模式/难度最快通关
- 试炼：Lv.8、7 次初始基因选择，强化五王连战；前四王各追加 2 次选择，入场恢复生命/能量与技能冷却；通关结算 80 精华
- 已有内容：15 处探索事件、45 个成本/奖励选项、8 件战斗遗物、8 项跨旅程成就
- 探索：靠近金色地标后按 F / 触屏调查；选择时世界暂停；图鉴和成就在菜单或旅途记录中查看
- 存档：兼容 0.4 / 0.5 旅程与永久成长；旧通关解锁试炼，但不伪造历史战绩；继续旅程不重复施加出身属性。战绩仅存于当前浏览器，不是线上排行榜
- 画面：原始 PNG、Three.js 透视场景、灯光、阴影和后处理保留；新增补给使用实际三维网格和共享几何，兼容路径也显示对应物件
- 战斗：Z / 触屏主动三段撕咬、三种精英词缀、五区限时狩猎、战利品与区域机关
- 已有触控输入保留兼容，本轮不新增手机专用功能
- 兼容：WebGL 可用时始终运行 Three.js 三维 HD-2D；WebGL 被宿主禁用时自动切换 Canvas，并以带屋顶纵深、侧墙、投影、梁柱、门窗和区域差异建筑的 2.5D 兼容画面继续运行，不再显示平面房屋占位图。右下角明确显示当前渲染模式
- 性能：静态角色图集由 16 个重复 GPU 纹理改为 1 个共享纹理与每角色独立 UV
- 建议：桌面 Chrome/Edge，开启浏览器硬件加速
- 构建：index.html 自包含可编辑程序，15 个经典内联脚本，7 张嵌入 PNG，无外部启动依赖
- 恢复：原 scratch 模块工程被平台维护清理，本轮从 afbc63a 的已发布完整内联程序恢复后继续开发；运行代码、素材、测试与发布说明纳入 Git
