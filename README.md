# 噬界 · HD-2D Web

同一份 Web 游戏同时支持桌面键鼠和手机浏览器触控。保留既有五区域、角色动作帧、真实三维建筑与 Three.js HD-2D 渲染；不另做简化手机版。

- 版本：0.10.0 WEB（抽象剧情、NPC 梗气泡与可交互区域内容；公开 Pages 与 iPhone 实机验收仍需单独确认）
- 手机入口：在 Safari / Chrome 打开完整 HTTPS 游戏页面。iPhone 附件/文件预览不能作为可玩交付；无脚本时显示入口说明，隐藏未运行的游戏界面
- 触屏：左手摇杆持有独立指针，右手可同时按技能；技能按下即施放，抑制重复合成点击；摇杆死区、取消触摸、失去捕获、切后台及旋转屏幕均清除残留输入
- 布局：同一游戏 UI 按横竖屏重新排布，适配安全区和动态可视高度；镜头控制收进右上角面板，避免挡住技能；长菜单/升级/探索面板可滚动
- 启动：图集顺序解码以减少同时解码的临时资源需求，不缩减素材；每个启动阶段连续 25 秒无进展才报错，正常慢加载不会因为累计超过 25 秒误报
- 三维村庄：WebGL 场景补齐第四栋实体房屋，与四块碰撞区和小地图完全一致；每栋均由墙体、屋顶几何、瓦片、烟囱、门窗、道具和灯光组成
- 建筑动态：房门是独立三维网格，角色靠近时绕真实铰链平滑开合；烟囱具有分层上升和渐隐的空间烟雾，减少静态模型感；减少动态效果设置下会安全降级为定格状态
- 精准闪避：敌方攻击实际命中的 0.3 秒内按 Q 冲刺可无伤闪避，获得 16 点终极能量并削减 1 秒脉冲冷却；每次冲刺只可触发一次
- 统治者破势：对同一 Boss 完成 3 次精准闪避，清除其尚未触发的攻击和在场弹幕，打开 2.5 秒破势窗口；窗口内承受伤害提高 35%，Boss HUD 实时显示破势进度
- 新内容：每个战役区域 6 个可破坏补给，共 30 处；补给箱、精华罐、经验罐分别掉落生命/精华/经验，需拾取，已破坏状态保存在本局；试炼不额外投放补给
- 新内容：五个区域各加入 2 名 NPC，共 10 名；每名 NPC 有 3 条循环头部梗气泡、一次性奖励与本局交谈记录，WebGL 和 Canvas 路径都绘制对应角色标记
- 抽象剧情：五段区域回声把“被丢弃的意识、无名的饥饿、英雄形状的空洞、被同意的边界、规则的余味”串成一条主题线；进入区域与 J 旅途记录可查看
- 连噬：4 秒内继续吞噬延续计数，3 连起每次额外恢复 1–5 点终极能量；受伤或超时中断。伤害数字、终结击大字与剩余连噬时间直接反馈
- Web 操作：WASD 移动，Z 或鼠标右键定向撕咬，Space 脉冲、Q 冲刺/精准闪避、E 终极、F 调查/出口；滚轮或滑条 75–135% 缩放；P 暂停观景，P/Esc/按钮退出，观景时战斗冻结
- 成长：4 种出身、通关后五王试炼、最近 8 局战绩与分模式/难度最快通关
- 试炼：Lv.8、7 次初始基因选择，强化五王连战；前四王各追加 2 次选择，入场恢复生命/能量与技能冷却；通关结算 80 精华
- 已有内容：15 处探索事件、45 个成本/奖励选项、8 件战斗遗物、8 项跨旅程成就
- 探索：靠近金色地标后按 F / 触屏调查；靠近 NPC 可按 F / 触屏交谈并领取一次奖励；选择时世界暂停；图鉴、成就、剧情回声与 NPC 记录在菜单或旅途记录中查看
- 存档：兼容 0.4 / 0.5 旅程与永久成长；旧通关解锁试炼，但不伪造历史战绩；继续旅程不重复施加出身属性。战绩仅存于当前浏览器，不是线上排行榜
- 画面：原始 PNG、Three.js 透视场景、灯光、阴影和后处理保留；新增补给使用实际三维网格和共享几何，兼容路径也显示对应物件
- 战斗：Z / 触屏主动三段撕咬、三种精英词缀、五区限时狩猎、战利品与区域机关
- 原画质约定：所有设备默认精致档，不按手机型号/触摸输入降低渲染质量。旧版本未明确选择过的低画质设置会重置为精致；之后玩家手动选择的流畅档仍保存
- 兼容：WebGL 创建失败时停止并明确报告，不自动切换成 Canvas。只有玩家点击“我选择 2D 兼容画面（会降低画质）”或主动使用 renderer=canvas 参数才启用旧兼容渲染器，界面标明并非原版三维画面。WebGL 上下文丢失会暂停、尝试保存并要求重新加载原画质
- 性能：静态角色图集由 16 个重复 GPU 纹理改为 1 个共享纹理与每角色独立 UV
- 建议：桌面 Chrome/Edge 或支持 WebGL 的手机 Safari/Chrome，使用完整在线页面；手机性能与真实排版仍待实机验收，不保证所有设备帧率
- 构建：index.html 自包含可编辑程序，17 个游戏模块脚本，7 张嵌入 PNG，无外部启动依赖。桌面离线文件仍保留，但不能把下载 HTML 的附件预览当作手机游戏
- 恢复：原 scratch 模块工程被平台维护清理，本轮从 afbc63a 的已发布完整内联程序恢复后继续开发；运行代码、素材、测试与发布说明纳入 Git
